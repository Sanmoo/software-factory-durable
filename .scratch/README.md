# Arquivo do tracker Markdown local

Este diretório foi o issue tracker do repositório até 2026-11-22. Desde então o tracker é o GitHub
Issues (ver [docs/agents/issue-tracker.md](../docs/agents/issue-tracker.md)).

- Tickets resolvidos, specs, mapas, PRD e pesquisas continuam válidos como referência e podem ser citados
  por caminho.
- Nenhum ticket, spec ou mapa novo nasce aqui.
- Os tickets que estavam abertos migraram para issues; a linha `Status:` de cada arquivo migrado aponta
  para a issue, que passou a ser a versão canônica.
- Os números de ticket nestes arquivos são locais a cada feature; `#n` no GitHub é outro espaço de números.

Os diretórios `factory-development-*` não fazem parte do arquivo: são cópias preparadas do SDK privado,
fora do controle de versão.
